GEOSCAN

Планирование маршрута БВС для аэросъёмки

Параметры полёта

Как пользоваться:
1. Нажми «Нарисовать территорию».
2. Кликай по карте по углам области.
3. Нажми на первую точку ещё раз — полигон замкнётся.
4. (Опционально) Нарисуй запретные зоны.
5. (Опционально) Добавь резервные площадки.
6. Настрой параметры и нажми «Рассчитать маршрут».
